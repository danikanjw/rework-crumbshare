# 🍞 CrumbShare

A food donation platform that connects people with surplus food to people who need it, helping reduce food waste and support local communities.

> This project is a rework of my previous CrumbShare project, rebuilt with a modern full-stack architecture and improved functionality.

## ✨ Features

- User authentication and session management
- User profile management
- Create and manage food donations
- Food image upload
- Browse available food donations
- Food discovery by location
- Claim available food
- Donation and claim history
- Food expiration handling
- Responsive user interface

## 🔄 Project Background

CrumbShare was originally developed as a food donation web project.

This repository is a reworked version of the [original project](https://github.com/danikanjw/CrumbShare), rebuilt with a modern full-stack stack and improved functionality.

The rework focuses on:

- Improved application functionality
- Better authentication and session handling
- Database integration with Prisma and PostgreSQL
- Structured API routes
- Improved user experience
- Production deployment
- More maintainable project structure
